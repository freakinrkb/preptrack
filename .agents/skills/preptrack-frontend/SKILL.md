# PrepTrack frontend

Implement the smallest accessible interface that helps a learner start, record, and revisit work.

- Surface source attribution and canonical external links on imported entries.
- Keep DSA company-first; use topic/format navigation for System Design and LLD.
- Respect each user’s difficulty display preference; hide labels when off without changing data or filtering results.
- Distinguish completion, confidence/independence, and strength. Strength needs a sample-size hint.
- Work well at mobile width and use keyboard-accessible controls, labelled forms, clear focus, and plain-language empty/error states.

Read `docs/PRODUCT_PLAN.md` for page acceptance criteria. Do not add an editor, compiler, or diagram canvas unless scope explicitly changes.
